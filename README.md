# mosque_finder
A project where users can search for mosques and filter for mosques based on certain conditions. Users can also add or remove mosques and edit mosque information.

In order to be able to run the app, go to the terminal and type in streamlit run hello.py
You will need to have streamlit installed of course (as well as a few other uncommon modules that I have used)

# Please bear in mind you may need to double click to view, edit, remove etc.
